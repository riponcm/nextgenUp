# NextGenUp launch kit

Everything needed to launch and promote NextGenUp, in one folder.

## Contents

| Folder / file | What it is | Where to use it |
|---|---|---|
| `logo/icon_1024.png` | App icon, largest master | Press, listings, anywhere |
| `logo/icon_512.png`, `icon_256.png`, `icon_128.png` | Smaller icon sizes | Avatars, favicons, profiles |
| `logo/icon.icns`, `logo/icon.ico` | Native icon bundles | macOS / Windows packaging |
| `banners/hero.gif` | Animated banner (900x300) | README, blog posts, embeds |
| `banners/social-preview.png` | Share card (1280x640) | GitHub Settings > Social preview; Twitter/X, LinkedIn, Discord cards |
| `screenshots/compare.png` | Before/after slider, mac window frame | Anywhere a hero screenshot is needed |
| `screenshots/modes.png` | Image mode selection | Feature walkthroughs |
| `screenshots/video.png` | 4K video upscale in progress | Feature walkthroughs |
| `screenshots/batch.png` | Batch processing grid | Feature walkthroughs |
| `product-hunt/01..05*.png` | Gallery slides (2540x1520, 2x of PH's 1270x760) | Product Hunt gallery, upload in order |
| `product-hunt/copy.md` | Tagline, description, topics, maker comment, tips | Product Hunt submission |
| `hacker-news/post.md` | Title options, first comment, tips | Show HN submission |

## Quick launch checklist

1. GitHub Settings > General > Social preview: upload `banners/social-preview.png`
2. Product Hunt: follow `product-hunt/copy.md`, gallery images in order
3. Hacker News: follow `hacker-news/post.md`
4. Reply to comments quickly on launch day
